# profile-cam(横顔撮影アプリ)

卒業研究「舌トレーニングのゲーム化の効果」で、MC角(G–Pog–Me–C)を比べるための横顔写真を、毎回同じ条件で撮るためのアプリです。iPhone の Safari で動く、1つの `index.html` だけでできています。

- 公開先: https://lions12142004-png.github.io/profile-cam/
- 対応端末: iPhone 11 / iPhone 17e(背面の広角カメラ 1×、横向き)
- 撮影方法は Namura et al. (2008) にそろえています(距離 900 mm、HRL を床と平行)

## できること

- スマホの傾き(前後・左右)、HRL、顔とカメラの高さ、距離、静止、ブレを判定し、すべての条件がそろったときだけ自動でシャッターを切ります。
- 2回目以降(T1・T2)は、1回目(T0)と同じ画角になるまで撮影しません。T0 の写真を重ねて表示し、ずれの直し方を文字と音声で案内します。
- 目尻と耳の付け根は、静止画で撮影者がタップして指定し、その後は映像の追跡で自動的に更新します(マーカー不要)。
- 撮影時の条件の値をすべて記録し、CSV で書き出せます。

## 使い方(要約)

1. iPhone を三脚に横向きで固定し、Safari で上の URL を開きます。
2. 参加者ID・時点(T0/T1/T2)・顔の向きを入れ、横向きのまま「開始」を押します。カメラと「動作と方向」を許可します。
3. 「静止画で点を指定」で目尻と耳をタップし、「決定して追跡を始める」を押します。
4. T0 では、メジャーで 900 mm を確認して「900 mm を確認した」を押します。
5. 画面の案内に従って合わせ、「撮影待機を始める」を押すと、条件がそろったときに自動で撮影します。条件がそろわないときは「手動で撮る」も使えます。
6. 確認画面で「保存する」→「画像を保存」で写真アプリに保存します。T0 を保存すると、その参加者の基準データができます。

## 本番前に1回だけ行うこと

- 設定 →「センサーの水平校正」: 水平器で合わせた状態を 0° にします。
- 設定 →「カメラ校正」: 900 mm の位置に置いた 100 mm の線を撮り、mm での案内を正確にします。
- カメラを上に向けて「上向き」と出るか確認します。逆なら設定の「ピッチの符号を反転」をオンにします。

## データの保存場所

- 写真: 保存時に選んだ場所(写真アプリ、またはファイルアプリ)
- 基準データと記録: その iPhone の Safari の中(IndexedDB)
  - Safari のタブで開く場合と、ホーム画面のアイコンから開く場合とでは、保存場所が別になります。
  - Safari の「Webサイトデータの削除」をすると消えます。開始画面の「基準データを書き出す」で控えを取ってください。

映像と写真は iPhone の中だけで処理し、外部には送信しません。外部との通信は、ページとライブラリ(OpenCV.js、MediaPipe)の読み込みだけです。

## 更新のしかた

1. 新しい `index.html` を、このリポジトリの「Add file」→「Upload files」で上書きして「Commit changes」を押します。
2. 1〜2分後、iPhone でページを開き直し、開始画面の一番下の版の番号が変わったことを確認します。
   - 番号が変わらないときは、URL の後ろに `?v=2` などを付けて開くと、古い表示(キャッシュ)を避けられます。
